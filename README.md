# TicTacToe
Acesta este unul dintre primele mele proiecte in Java, anul 2022 august, realizat dorind să fac și o interfață grafică a <a href="https://github.com/four436/Proiecte-clasa-a-IX-a/tree/main/Tic%20Tac%20Toe">jocului în terminal</a>.  
## Dependințe
Librăriile folosite:  
  * javax.swing
  * java.awt
  * org.w3c.dom.events.EventListener
    - folosite pentru realizarea interfaței grafice
## Descrierea interfaței  
La rularea progrmaului se deschide o fereastră care conține titlul jocului, un buton pentru a începe un joc și un buton pentru a inchide aplicația.  
Butonul **Player v.s. Player** te redirecționează la o pagină unde trebuie inserate numele celor doi jucători și un buton de **Start**. La apăsarea butonului de **start** te va trimite la pagina unde se desfășoară jocul, unde în patea de sus spune a cui jucător îi este rândul, iar în restul ecranului se află tabla de joc.  
## Rularea programului
  * se descarcă sau se face o clonă la repositorie
  * se adaugă în IDE-ul favorit
  * versiunea de Java trebuie sa fie minim 8.0
  * se rulează programul
